# 🌤️ AtmosAI

### Intelligent Real-Time Weather Assistant

AtmosAI is a modern AI-powered weather application that combines
real-time weather data with Gemini to provide clear and natural
weather insights for cities around the world.

Built with a clean, responsive interface designed to make checking
the weather fast, simple, and comfortable.

---

## ✨ Features

- 🌍 Search weather for cities worldwide
- ⚡ Real-time weather information
- ✦ AI-generated weather summaries
- 📱 Responsive and mobile-friendly interface
- 🎨 Clean, modern light-mode UI
- 🔎 Quick search for popular cities
- ⌨️ Keyboard-friendly city search
- 🚦 Clear loading and error states

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React | Frontend application |
| Vite | Development & build tooling |
| Tailwind CSS | UI styling |
| FastAPI | Backend API |
| Python | Backend logic |
| Gemini | AI weather assistant |
| OpenWeatherMap | Real-time weather data |
